## Mandatory UX requirements

### 1. Fully bilingual from the beginning

The MVP must support both:

* English
* Arabic

This is NOT a future feature.

Requirements:

* A clear language switcher available in the main application UI.
* When Arabic is selected, all user-facing interface text must be Arabic.
* When English is selected, all user-facing interface text must be English.
* Arabic must use proper RTL layout.
* English must use proper LTR layout.
* Tables, forms, cards, navigation, buttons, validation messages, empty states, alerts, filters, and dashboard content must all correctly follow the selected language and direction.
* AI-generated summaries must follow the currently selected language.
* User-entered data itself should not be translated or modified merely because the UI language changes.
* The layout must not depend on English text lengths.
* Avoid hardcoded mixed-language UI strings.

The implementation plan should include a clean localization/i18n approach rather than duplicating the entire interface.

### 2. Truly responsive

The application must be designed from the beginning for:

* Mobile phones
* Tablets / iPads
* Laptops
* Desktop screens

Do not treat responsiveness as a final visual patch.

The plan should explicitly address:

* mobile navigation
* responsive forms
* tables that remain usable on narrow screens
* cards and dashboard metrics
* job-detail views
* comparison views
* buttons and controls that remain easy to use by touch
* Arabic RTL behavior at mobile widths
* no horizontal overflow
* no broken layouts at narrow widths

The interface should remain professional and usable rather than simply shrinking desktop components.

### 3. Visual design and color system

Visual quality is a major requirement.

Do NOT use random colors or an overly generic dashboard template.

Create a coherent B2B product visual identity suitable for a modern manufacturing SaaS product.

The color system should:

* look professional and trustworthy
* have a clear primary brand color
* use restrained secondary colors
* distinguish Good Output, Scrap, Reusable Offcuts, and Rework clearly
* maintain sufficient contrast and accessibility
* never rely on color alone to communicate meaning
* remain visually consistent in both Arabic and English
* work well on light backgrounds
* avoid excessive gradients, neon colors, or unnecessary visual effects

The dashboard should feel polished enough for a real factory manager demonstration.

### 4. Design priority

Prioritize:

1. clarity
2. usability
3. trustworthy production data
4. responsive behavior
5. bilingual quality
6. polished visual hierarchy

Do not add decorative features that do not improve the product.
